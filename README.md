Fetching and Displaying API Data with JavaScript

This project demonstrates how to fetch and display user data from a public API (https://jsonplaceholder.typicode.com/users) using the JavaScript Fetch API with async/await. The data is parsed as JSON and dynamically displayed in styled user cards.

Key features:
	•	Asynchronous Fetching: Uses async/await to handle API requests smoothly.
	•	Error Handling: Displays error messages and provides a retry option if the network fails.
	•	Interactivity:
	•	Search bar to filter users by name or email.
	•	Sort dropdown to order users alphabetically (A–Z or Z–A).
	•	Show/Hide Details button for toggling extra info (address, phone, company).
	•	User Experience Enhancements: Loading animation, styled UI with CSS, and a reload button to refetch data.

Outcome:
Through this project, we learn how to work with APIs, JSON parsing, DOM manipulation, event handling, and error management in JavaScript while building an interactive and user-friendly web application.
